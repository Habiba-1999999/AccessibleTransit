Our Features

Accessible Transit provides a set of tools that helps communities identify, report and understand accessibility barriers in public spaces.

🗺️

Interactive Map

Users can explore an interactive map and select the exact location of an accessibility problem.

🚧

Barrier Reporting

Report accessibility barriers such as broken ramps, blocked sidewalks, broken elevators and uneven roads.

📸

Image Upload

Attach an image to a report to provide visual evidence of the accessibility problem.

🔴

Severity Classification

Classify each reported problem as High, Medium or Low severity.

📍

Location Capture

The selected map location provides latitude and longitude coordinates for accurate reporting.

👥

Community Reports

View accessibility reports submitted by other members of the community.

🔐

Secure Login

User registration and authentication help protect the reporting system.

📊

Dashboard

Users can view report statistics and quickly access the major functions of the application.

☁️

MongoDB Storage

User accounts and accessibility reports are stored in MongoDB for persistent data management.
